# Profile name fonts

These fonts are self-hosted; the browser does not contact Google Fonts. Each
family includes its original SIL Open Font License and copyright attribution.
Only Latin and extended Latin WOFF2 subsets are included where available.
The files are loaded on demand through `styles/profile-fonts.css` with
`font-display: swap`; they are not preloaded on every page.
